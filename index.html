    Upload New Test Series

    Fill in the details and add questions below.

    Enter the negative marks as a positive number (e.g. enter 0.5 to deduct 0.5 for each wrong answer). Leave blank to use the defaults (2 marks correct, 0.5 deducted).

    Divide this test into as many sections as you want (e.g. Reasoning, Maths, English) — each section can have its own time limit. If you just want one single timed test, keep it to 1 section.

    Fill in all 4 options for each question and select the correct one with the radio button — or upload a .txt file per section instead of typing questions manually. You can optionally attach one image to any question (e.g. a diagram or figure) and one to its solution — leave blank if not needed. The same image is shown to students whether they're viewing the test in English or हिंदी. The dashed fields are for an optional Hindi translation of the text — fill them in if you want students to be able to switch the test to Hindi; leave them blank to keep the question English-only.
    Please fill the subject, title, and every section's name/time, and add at least 1 complete question per section.
